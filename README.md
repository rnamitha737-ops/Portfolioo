# Namitha Reddy — Developer Portfolio 🚀

A modern, high-performance, and responsive personal portfolio website built with **React**, **TypeScript**, and **Vite**.

Designed with sleek glassmorphism aesthetics, interactive developer terminal, comprehensive project showcases, skill progression matrix, and smooth animations.

---

## ✨ Features

- **⚡ Blazing Fast Performance:** Powered by Vite & React 18 with TypeScript.
- **💻 Interactive Developer Terminal:** Functional in-browser terminal supporting custom commands (`help`, `skills`, `projects`, `contact`, `clear`, etc.).
- **🎨 Modern Dark Aesthetic:** Curated color palette, glowing gradients, glassmorphism cards, and responsive typography (Plus Jakarta Sans & JetBrains Mono).
- **📂 Project Showcase:** Detailed project breakdowns with tech tags, descriptions, GitHub links, and live demos.
- **📊 Skills & Engineering Focus:** Highlighting core competencies in Java, DSA, Web Development, SQL/DBMS, and Developer Tooling.
- **📱 Fully Responsive:** Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, CSS3
- **Build Tool:** Vite
- **Typography:** Plus Jakarta Sans, JetBrains Mono
- **Deployment Ready:** Vercel / Netlify / GitHub Pages

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rnamitha737-ops/Portfolioo.git
   cd Portfolioo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
